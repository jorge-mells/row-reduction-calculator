# Row Reduction Calculator

An interactive row-reduction calculator for working with matrices using exact arithmetic.

The project is designed around entering **row operations** rather than manually entering each resulting matrix. It supports common elementary row operations, exact fractional arithmetic, keyboard navigation, undo/redo, operation history, and drag-and-drop row selection.

## Features

* Exact arithmetic using fractions
* Row addition
* Row swapping
* Row scaling
* Linear combinations of rows
* Undo/redo
* Complete operation history
* Keyboard navigation
* Drag-and-drop row operations
* Matrix resizing
* React + TypeScript frontend
* UI-independent matrix/operation engine

## AI-generated project

This project is **fully AI-generated**.

The implementation, architecture, and much of the code were produced collaboratively with an AI assistant. The human contribution is primarily the project direction: deciding what to build, how it should behave, which technologies and abstractions to use, and reviewing the resulting implementation.

The project is intentionally kept as a real software project rather than an AI-generated code demonstration. Its purpose is to explore what happens when AI is used as the primary implementation tool while the developer remains responsible for the design and technical decisions.
